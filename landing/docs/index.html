01 Getting started

Quick start#

  1. Add Reiner to your server and drag its role near the top of Server Settings → Roles.
  2. Create a role named exactly DEV and give it to yourself.
  3. In a private channel, send @Reiner admin channel here.
  4. Send @Reiner start setup and reply 6 to set up everything.
  5. Run /dashboard to get a 24-hour login link to the Command Center.

The DEV role#

Reiner decides who's staff by a role named DEV. It checks the role's name, not its permissions, so the name must match exactly, in capitals. Members with DEV can run the setup wizard, set the admin channel, open the dashboard and manage points.

DEV members are excluded from MMR, and in League votes a DEV vote counts as 999 (see DEV vote power).

Without the role, Reiner replies “You need the DEV role to start setup.”

Admin channel#

Create a private text channel, then mention the bot there. From then on, admin commands only work in this channel.

@Reiner admin channel here
Reiner This channel has been set as the admin channel. All admin commands must now be used here.

02 Games

Imposter#

A social deduction word game played in a voice channel. Everyone gets the same secret word, except the imposter(s), who get a blank. Players take turns dropping subtle hints, then everyone votes on who they think the imposter is. A great warm-up before custom lobbies.

How to play: join a voice channel and run /imposter. The bot DMs each player their word (or “imposter”), runs the hint rounds, then the vote.

League of Legends quiz#

A live, on-demand League quiz. Members guess the champion from cropped splash art, ability icons and descriptions, lore excerpts, titles and skins, answered through the dropdown on the question. Correct answers earn points and build a streak bonus.

How to start: run /quizz in any channel. Rewards: +5 per correct answer, with streak bonuses up to +10. Setup option 15 adds a daily League question.

03 League custom lobbies

How a lobby runs#

  1. Players join the Queue Lobby voice channel.
  2. Members vote on the team format; the bot moves everyone into Team 1 and Team 2.
  3. Roles are decided, you play the game, then everyone votes the winner.
  4. MMR is paid out and the result posts to your match-history channel.
Set it up: @Reiner start setup → option 16. The bot needs the Move Members permission to move players into team channels.

DEV vote power#

In every League vote (team format, captain and player picks, role mode, and the winner), a vote from a DEV member weighs 999 instead of 1. A single DEV vote overrides the lobby and decides the outcome instantly, so staff can settle a result or push teams through without waiting on everyone. Regular members always count as 1.

Match history#

Pick any text channel and every finished lobby's result is posted there automatically: a running log of who beat who, with each player's MMR change.

Set it up: setup option 21, or right-click a text channel on the dashboard → Set as match history channel.

04 Points & MMR

MMR & ranks#

Every member has an MMR number and a rank that follows it. A normal win is +50 and a normal loss −50, but recent form bends the number: a comeback win after losses gives less, and a loss after a strong win streak is cushioned. Voting for the winner is always +2. DEV and NPC members are excluded from MMR.

League-only & nicknames#

Two toggles live in the dashboard under Settings:

Activity points

Earn MMR from chatting and voice time. Turn this off so League custom lobbies are the only way to gain MMR.

Points on nicknames

Show each member's MMR as Name [123] on their nickname. On for a visible ladder, off to keep names clean. Also setup option 19.

05 Dashboard

Logging in#

Run /dashboard in your server (needs the DEV role). The bot DMs you a private login link, valid for 24 hours and scoped to your server only. If your DMs are closed, it shows you the link privately instead. Super admins sign in with a username and password and can manage every server.

Reiner I sent your 24-hour login link to your DMs.

Open the dashboard

Leaderboard & editing MMR#

The Points tab shows the live leaderboard. Hit Edit on anyone to add, remove, set or reset their MMR. It syncs straight to Discord, so ranks and nicknames update. Search a member by name to adjust them even at 0.

Troubleshooting#

“You need the DEV role…”
Create a role named exactly DEV and assign it to yourself.
Admin command ignored
Use it in the channel set with @Reiner admin channel here.
Setup doesn't respond
Mention the bot (@Reiner), not just the word “Reiner”.
Rank roles don't update
Move Reiner's role above them in Server Settings → Roles.
Players aren't moved to teams
Give Reiner the Move Members permission.
No /dashboard command
Run setup option 20, or 1 to register all commands.
