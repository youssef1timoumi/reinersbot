  • Custom lobbies: an admin posts the queue with /sendqueue, players join the Queue Lobby voice channel until it's 10 of 10, Reiner sets two teams balanced by MMR, moves them to voice and posts the result: +50 MMR for winners, −50 for losers.

02 How to use

Set up in five minutes. Two rules, then a wizard.

Reiner only takes setup and admin commands from people with the DEV role, and only inside your admin channel. Get those two right and the setup wizard handles the rest.

roleDEV channel#admin

The role must be called DEV, in capitals. Reiner checks the role's name, not its permissions.

  • A role named DEV, given to you and any co-admins.
  • A private admin channel where setup and admin commands run.
  • Reiner's role near the top of the role list, so it can assign rank roles.
  1. 01

    Add Reiner to your server

    Click Add Bot to Discord, pick your server and keep the requested permissions. Reiner manages roles, channels and nicknames for ranks and lobbies.

    Then open Server Settings → Roles and drag Reiner above the roles it should manage. Discord bots can only assign roles below their own.

  2. 02

    Give yourself the DEV role

    In Server Settings → Roles, create a role named exactly DEV and assign it to yourself. Without it, Reiner replies: “You need the DEV role to start setup.”

    DEVassigned to you
  3. 03

    Set your admin channel

    Create a private text channel, for example #reiner-admin, then mention the bot there:

    @Reiner admin channel here
    Reiner This channel has been set as the admin channel. All admin commands must now be used here.
  4. 04

    Run the setup wizard

    In the admin channel, start the wizard and reply with a number. 6 runs everything; or pick only what you need:

    @Reiner start setup
    6Complete setup 1Slash commands 5Points & ranks 16Custom lobbies 21Match history 15Daily quiz 20Dashboard access
  5. 05

    Open the Command Center

    Run /dashboard (installed by wizard option 20). Reiner DMs you a login link that's valid for 24 hours. No account or password needed.

    Reiner I sent your 24-hour login link to your DMs.
  6. 06

    Let your members in

    Everyone else types /reinerhelp to see what they can do: join lobbies, play Imposter and trivia, check /me, start timers, or just @Reiner in plain English.

Reiner not responding?

  • The role must be named exactly DEV (capitals), and you must have it.
  • Admin commands only work in the channel you set with @Reiner admin channel here.
  • Setup commands need a real mention of the bot (@Reiner), not just the word “Reiner”.
  • Rank roles not updating? Move Reiner's role above them in Server Settings → Roles.

03 FAQ

Questions, answered.

Can't find it here? Check the docs or get in touch.

What is Reiner?

Reiner is an all-in-one Discord bot built for League of Legends communities. It runs custom lobbies (in-house games) with MMR, has built-in mini-games (Imposter and live League trivia), AI chat, a points and rank system, focus timers, moderation tools, and a web dashboard called the Command Center.

How do League of Legends custom lobbies work in Discord?

Players gather in the queue lobby voice channel. Members vote on the team format, Reiner moves everyone into Team 1 and Team 2 voice channels, you play, then everyone votes the winner. Winners get +50 MMR and losers −50, adjusted for streaks, and setup option 21 posts every result to a match history channel.

What games can my Discord server play with Reiner?

Imposter, a social deduction word game themed on League champions, items and terms (/imposter). A live League quiz where members guess champions from splash art, abilities, lore and titles (/quizz). And a daily League question (/dailyq), posted every day at 20:00.

Why do I need a role called DEV?

Reiner uses a role named exactly DEV to decide who can run setup and admin commands, open the dashboard and manage points. Create it in Server Settings → Roles and give it to yourself and any co-admins.

Why isn't Reiner responding to setup commands?

Check three things: you have the DEV role (exact spelling), you're in the admin channel you set with “@Reiner admin channel here”, and you actually mentioned the bot with @Reiner.

How do I log in to the Reiner dashboard?

Run /dashboard in your server (DEV role required). Reiner DMs you a private login link that lasts 24 hours and only works for your server. There's no separate account or password. If /dashboard isn't available yet, run setup wizard option 20.

Does Reiner have a points and leveling system?

Yes. Members earn points from lobbies and activity (chat and voice time), and climb rank roles from Unranked through Bronze, Silver, Gold and Diamond to Master. /me shows your progress and /ld the leaderboard. Admins can switch activity points off so lobbies are the only way to earn.
