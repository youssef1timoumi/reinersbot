# Privacy Policy

**Effective Date:** January 2025

## 1. Information We Collect
- Discord User ID (for identification)
- Server/Guild ID (for server-specific features)
- Message metadata (timestamps, channel IDs)
- Points and ranking data
- Voice channel activity duration

## 2. How We Use Information
- Provide bot functionality (points, moderation, support)
- Track user progress and rankings
- Prevent spam and abuse
- Improve bot performance

## 3. Data Storage
- Data is stored locally on bot servers
- No data is shared with third parties
- Data is retained while bot is active in server

## 4. Data Security
- Access restricted to bot administrators
- Data encrypted in transit
- Regular security updates applied

## 5. Your Rights
- Request data deletion by leaving server
- Opt out of points system via "No Ranks" role
- Contact administrators for data inquiries

## 6. Third-Party Services
- Uses Discord API (subject to Discord's Privacy Policy)
- May use AI services for chat features
- No personal data shared with external services

## 7. Children's Privacy
- Bot complies with Discord's age requirements
- No additional data collected from minors

## 8. Changes to Policy
- Updates posted with effective date
- Continued use implies acceptance

## 9. Contact
For privacy concerns, contact bot administrators.
